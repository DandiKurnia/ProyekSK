## 5. Rencana (disetujui, BELUM dieksekusi) — ESP32 Fingerprint via USB Serial

- **Topologi (klarifikasi):** Laptop --USB/COM--> ESP32 --UART--> sensor R503. ESP32 tetap dipakai sebagai mikrokontroler pengendali R503 (face service TIDAK bicara langsung ke R503). Daya ESP32 + R503 dari port USB laptop.
- **Kenapa:** Daya dari laptop (tanpa adaptor); latency ms bukan detik; hapus tabel `device_commands` + logika antrean polling; 2FA selesai lokal di PC, cloud terima 1 hasil final.
- **Catatan:** ESP32 Kursi (HX711) tetap Wi-Fi — tidak mungkin tarik USB ke tiap bangku.
- **Dampak PRD (status: TERENCANA, belum diubah):** `docs/fingerprint.md`, `docs/architecture.md`, `docs/backend.md`, `docs/communication-flow.md`, `docs/database.md` (§ device_commands), `docs/face-recognition.md` (sequence), `prd-devices.md`, `prd-students.md`, `prd-attendance.md` masih tulis polling — lihat §6 Audit PRD di bawah.
- **File kode (belum ada):** `apps/face-service/fingerprint_serial.py` + firmware `apps/fingerprint-esp32/` — dibuat saat hardware tersedia.
