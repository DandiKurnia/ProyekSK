> Changelog harian. Format: Apa → Kenapa → File terdampak → Status uji.

## 1. Login staf + guard route

- **Apa:** halaman `/login` (email + password, pesan error generik, toggle tampil password, return URL `next`, pesan "Sesi berakhir, silakan login kembali" bila cookie sesi lama masih ada). `src/middleware.ts` menolak halaman tanpa sesi ke `/login?next=<path>` dan memantulkan sesi valid dari `/login` ke `/`. `/api/*` dikecualikan — face service & ESP32 memanggil Route Handler tanpa sesi staf. Role/status diambil server-side via `GET /api/auth/me` (`profiles`: `full_name`, `role`, `is_active`; tanpa profil atau nonaktif → signOut + "Akun dinonaktifkan"). Topbar tampilkan nama + role asli dan menu Keluar (`POST /api/auth/signout`). Sesi cookie httpOnly via `@supabase/ssr` 0.12.7.
- **Kenapa:** seluruh 7 menu wajib di balik guard (PRD auth §1–§6); progres "Belum: Login/Auth" tersisa dari 2026-11-17.
- **File terdampak:** `apps/web/package.json` (+`@supabase/ssr`), `src/middleware.ts`, `src/lib/supabase-{browser,session}.ts`, `src/app/login/page.tsx`, `src/app/api/auth/{me,signout}/route.ts`, `src/components/Topbar.tsx`, `README.md`, `docs/dashboard.md`.
- **Status uji:** `tsc` bersih ✅; `next build` sukses (`/login` 2.2 kB, middleware 92.4 kB) ✅; uji live `:3000` ✅ — `/` tanpa sesi → 307 `/login?next=%2F`; password salah → "Email atau password salah"; login → ke `/settings` (return URL) dengan Topbar "Admin AICI / ADMIN"; logout → `/login`; akses langsung setelah logout → redirect `next=%2Fattendance`; cookie sesi palsu → pesan sesi berakhir tampil.
- **Skipped:** rate limiting/lockout (PRD §4.4 masih `TBD`), reset password mandiri, auto-logout idle, UI sesi aktif, RBAC per halaman (role ditampilkan, akses belum dibatasi).
